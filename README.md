# Aly-Music-Player-AMP-
Music Player for hyprland with pywal colors

I'm back, i've been busy working on this music player for hyprland and pywal

It's named for my girlfirend Aly (Yes linux users can have girlfirends xd)

It's not done yet but its working fine at least

You can search by:
Files
Songs
Artist
Genres
Last played
Most listened
Favorites
Playlist

Also you can switch between wave and progress bar to see how music goes

This player changes its colors according to the wallpapers. I am doing this cause I didn't find any players who change its colors with pywal 

--Install--

Clone the repository
git clone https://github.com/Esrael509/Aly-Music-Player-AMP-.git

Go to the repository
cd Aly-Music-Player-AMP-/

Install the app with
./install
It automatically installs all the dependencies

Start AMP
aly-music-player

Enjoy!!!
